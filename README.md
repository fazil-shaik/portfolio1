Portfolio Website

## Website URL
[Visit the Portfolio](https://portfolio1-eight-kappa.vercel.app)

## Features
- **Dynamic Project Showcase**: Highlights major projects with descriptions, technologies, and links.
- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.
- **Interactive Animations**: Smooth transitions and engaging visuals using Three.js.
- **Modern Frameworks**:
  - Built with React.js for a seamless user interface.
  - Powered by Next.js for server-side rendering and optimized performance.
- **3D Elements**: Integrates Three.js for interactive 3D models and animations.
- **Contact Section**: Includes a functional contact form for visitors to reach out.

## Tech Stack
- **Frontend**: React.js, Next.js
- **3D Graphics**: Three.js
- **Styling**: Tailwind CSS / CSS Modules
- **Hosting**: Vercel
